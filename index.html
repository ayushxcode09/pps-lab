Theory · Module II
🔀 If-Else & Switch
Conditional branching — making decisions in code
Basic if-else
if(condition) { // runs if TRUE } else { // runs if FALSE } // Example: even or odd if(n % 2 == 0) printf("Even"); else printf("Odd");
Any non-zero value = true, 0 = false. Condition must be inside ().
if-else Ladder (exam favourite)
// Grade calculator — check from HIGHEST to lowest if(marks >= 90) printf("A"); else if(marks >= 80) printf("B"); else if(marks >= 70) printf("C"); else if(marks >= 60) printf("D"); else printf("F");
Check highest value first. If you check >=70 first, marks=95 also matches wrongly.
Nested if (without &&)
// Largest of 3 — WITHOUT using && if(a > b) { if(a > c) printf("a largest"); else printf("c largest"); } else { if(b > c) printf("b largest"); else printf("c largest"); }
Switch Statement
switch(op) { case '+': printf("%.2f", a+b); break; case '-': printf("%.2f", a-b); break; case '*': printf("%.2f", a*b); break; case '/': b!=0?printf("%.2f",a/b):printf("Div by 0"); break; default: printf("Invalid"); }
Missing break = fall-through — all cases after matching one also run. Always add break!
Switch can only compare int and char — NOT float, NOT ranges like >=90.
Multiple cases → same handler: case 'a': case 'e': case 'i': all go to vowel handler.

🔁 Loops & Patterns
Repeat code — for, while, do-while, nested loops
for loop
for(init; condition; update) { body } // Print 1 to N for(int i = 1; i <= n; i++) printf("%d ", i); // Array input for(i = 0; i < n; i++) scanf("%d", &arr[i]);
init
int i = 0
Runs once at start
condition
i < n
Checked before each iteration
update
i++
Runs after each iteration
body
printf(...)
Runs while condition is true
while loop
while(condition) { body } // checks BEFORE running // Reverse a number while(n != 0) { rem = n % 10; // last digit rev = rev * 10 + rem; // append n /= 10; // remove last digit }
Always ensure condition becomes false eventually — or infinite loop!
break and continue
// break — exit loop immediately for(i=2; i<=n/2; i++) if(n%i==0) { isPrime=0; break; } // found divisor, stop // continue — skip current iteration for(i=1; i<=10; i++) { if(i%2==0) continue; // skip even numbers printf("%d ", i); // prints odd only }
Star Pyramid — Nested Loop (exam guarantee)
// Centered pyramid — n rows for(i=1; i<=n; i++) { for(j=i; j<n; j++) printf(" "); // (n-i) spaces for(j=1; j<=2*i-1; j++) printf("*"); // (2i-1) stars printf("\n"); }
Formula to memorize: Row i → spaces = (n-i), stars = (2i-1)
Theory · Module III
📦 Arrays & Strings
Store multiple values, sorting, searching, string handling
Arrays
int arr[5] = {10,20,30,40,50}; // index: 0 1 2 3 4 arr[0] = 10; // first element arr[4] = 50; // last element (NOT arr[5]!) for(i=0; i<n; i++) scanf("%d", &arr[i]); // input for(i=0; i<n; i++) printf("%d ", arr[i]); // output
Index starts at 0! Array size n → valid indices: 0 to n-1. arr[n] = out of bounds error!
Bubble Sort — Must Know!
for(i=0; i<n-1; i++) { // n-1 passes for(j=0; j<n-i-1; j++) { // compare adjacent if(arr[j] > arr[j+1]) { // wrong order? t=arr[j]; arr[j]=arr[j+1]; arr[j+1]=t; // swap } } } // Descending: change arr[j] > arr[j+1] to arr[j] < arr[j+1]
Trace: {5,3,8,1} → pass1:{3,5,1,8} → pass2:{3,1,5,8} → pass3:{1,3,5,8}
Strings
char name[50] = "hello"; // stored as: h e l l o \0 ← null terminator marks end scanf("%s", name); // no & for strings! printf("%s", name); #include<string.h> strlen(s) // length (not counting \0) strcpy(dest, src) // copy string strcmp(s1, s2) // compare: 0 = equal // Palindrome WITHOUT strrev for(i=0; i<len/2; i++) if(s[i] != s[len-1-i]) { flag=0; break; }
Theory · Module IV
⚙️ Functions & Recursion
Reusable code, call by value vs reference, recursion
Function Syntax
return_type functionName(parameters) { return value; } int add(int a, int b) { return a + b; } int main() { int result = add(5, 3); // call → 8 return 0; }
Call by Value vs Call by Reference
// VALUE — copy passed, original unchanged void swapVal(int a, int b) { int t=a; a=b; b=t; // only copies change! } // REFERENCE — address passed, original changes void swapRef(int *a, int *b) { int t=*a; *a=*b; *b=t; // * = go to address } swapVal(x, y); // x, y unchanged swapRef(&x, &y); // x, y actually swapped!
Memory analogy: Value = photocopy (safe), Reference = original document (changes stick)
Recursion
int factorial(int n) { if(n==0||n==1) return 1; // BASE CASE — stop here return n * factorial(n-1); // RECURSIVE CALL } // factorial(4) = 4 × 3 × 2 × 1 = 24 int fib(int n) { if(n<=1) return n; return fib(n-1) + fib(n-2); }
Missing base case = infinite recursion = stack overflow = crash. Always add base case!
Base Case
if(n==0) return 1
When to STOP — mandatory!
Recursive Call
return n * f(n-1)
Smaller version of problem

🗂️ Structures & Pointers
Custom types, typedef, pointers, array of structs
Structure
struct Student { int roll; char name[50]; float marks; }; // semicolon here! struct Student s1; s1.roll = 101; // dot operator s1.marks = 89.5; scanf("%s", s1.name);
Array of Structures
struct Student s[5]; // 5 students for(i=0; i<5; i++) scanf("%d %s %f", &s[i].roll, s[i].name, &s[i].marks); // Find topper int maxIdx = 0; for(i=1; i<5; i++) if(s[i].marks > s[maxIdx].marks) maxIdx = i; printf("Topper: %s", s[maxIdx].name);
typedef struct
typedef struct { int id; char name[50]; } Student; Student s; // no need to write 'struct' keyword now
Pointers
int x = 10; int *p = &x; // p stores ADDRESS of x printf("%d", x); // 10 — value of x printf("%d", *p); // 10 — value AT address p *p = 99; // changes x to 99! // Swap using pointers void swap(int *a, int *b) { int t=*a; *a=*b; *b=t; } swap(&x, &y); // pass addresses
